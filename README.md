## 📖 Overview

**Cell Server AOT** is a carefully curated client-side Minecraft modpack designed for Minecraft 1.21.1 using the Fabric mod loader. This modpack focuses on enhancing the vanilla Minecraft experience with performance optimizations, quality-of-life improvements, visual enhancements, and gameplay additions while maintaining stability and compatibility.

The modpack includes:
- **72 mods** covering performance, visuals, utilities, and gameplay
- **Plain Craft Launcher 2 (PCL2)** for easy installation and management
- **25+ resource packs** for customized visuals
- **3 shader packs** for enhanced graphics
- Full Chinese language support with auto-translation features

**Design Goals:**
- Optimize client performance for smooth gameplay
- Enhance visual quality without sacrificing performance
- Add quality-of-life features for better user experience
- Maintain vanilla gameplay while adding useful tools
- Support both single-player and multiplayer experiences

## 🚀 Installation Instructions

### Prerequisites

1. **Java 21**: Download and install from [Oracle](https://www.oracle.com/java/technologies/downloads/#java21) or [Adoptium](https://adoptium.net/)
2. Minimum 4GB RAM (8GB+ recommended)
3. Windows, macOS, or Linux operating system

### Installation Steps

1. **Download the Modpack**
   - Clone or download this repository
   - Extract all files to a location of your choice

2. **Launch Plain Craft Launcher 2**
   - Run `Plain Craft Launcher 2.exe` (Windows)
   - For macOS/Linux, ensure you have a compatible Wine setup or use a native launcher

3. **Select the Modpack**
   - The launcher should auto-detect the "Bunker Server AOT" instance
   - Located in `.minecraft/versions/Bunker Server AOT/`

4. **Configure Java Settings** (Recommended)
   - Open launcher settings
   - Set Java version to Java 21
   - Allocate 4-8GB RAM (adjust `-Xmx` parameter)
   - Recommended JVM arguments:
     ```
     -Xmx6G -Xms4G -XX:+UnlockExperimentalVMOptions -XX:+UseG1GC -XX:G1NewSizePercent=20 -XX:G1ReservePercent=20 -XX:MaxGCPauseMillis=50 -XX:G1HeapRegionSize=32M
     ```

5. **Launch the Game**
   - Click "Launch" in PCL2
   - Wait for mods to load (first launch may take longer)
   - Enjoy!

## 💡 Tips & Recommendations

### Performance Tips

1. **Adjust Render Distance**: Start with 12-16 chunks, increase if performance allows
2. **Enable VSync**: Prevents screen tearing, caps FPS
3. **Monitor FPS**: Use Shift+F3 to view performance metrics
4. **Shader Performance**: Some shaders are more demanding than others
5. **Distant Horizons LOD**: Adjust quality in Video Settings > Distant Horizons

### Gameplay Tips

1. **Read Patchouli Books**: In-game guides for complex mods
2. **Use Waypoints**: Essential for navigation in large worlds
3. **Backup Regularly**: Advanced Backups runs automatically, but manual backups are recommended
4. **JEI Search**: Press "R" (recipe) or "U" (usage) while hovering over items
5. **Seasonal Awareness**: Crops grow differently in different seasons

### Multiplayer

- Compatible with vanilla 1.21.1 servers
- Some client-only mods won't affect server gameplay
- Disable incompatible mods if joining modded servers

### Troubleshooting

**Low FPS:**
- Reduce render distance
- Disable shaders
- Lower Distant Horizons quality
- Allocate more RAM

**Crashes on Launch:**
- Verify Java 21 is installed
- Check RAM allocation (minimum 4GB)
- Review crash logs in `.minecraft/logs/`

**Missing Textures:**
- Ensure resource packs are in correct order
- Some resource packs may conflict - try disabling some

**Mod Conflicts:**
- Check `latest.log` for error messages
- Disable suspected mods one by one
